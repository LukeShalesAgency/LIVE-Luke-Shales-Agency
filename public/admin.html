One place to check every client's chatbot, edit what it knows, and see who it flagged for you.

Add a new client

Paste their website URL. If they run separate sites — a main site plus a standalone FAQ or support site, say — add those too, one per line. This creates the client, crawls all of it, and drafts (and, unless you turn it off below, applies) their whole knowledge base — no other setup.

Active

Pausing stops the chatbot from answering questions on their site (it just says it's unavailable) without touching any code — use this if a client stops paying. It doesn't remove the embed code from their site; only they (or you, with their site access) can do that.
